# Materiały do seminarium DuckDB

Repozytorium zawiera skrypty pokazane przeze mnie na seminarium z przedmiotu
**Przetwarzanie danych w chmurach obliczeniowych**.

Porównanie zużycia zasobów dla przetworzenia syntentycznych danych poprzez DuckDB
oraz bibliotekę Pandas należy uruchomić narzędziem `uv`: `uv run ./demo_out_of_core.py`.
